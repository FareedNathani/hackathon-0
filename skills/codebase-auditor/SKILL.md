# Gold Tier Skill: Codebase Auditor
## Overview
This skill performs an automated, compliance-first audit of the project codebase. It follows the **MCP Server Pattern**, exposing tools and resources for systematic evaluation.

## Workflow
1. **Analyze Environment** (Resource)
2. **Execute Static Analysis** (Tool)
3. **Generate Audit Report** (Tool)
4. **Log Action** (Compliance)

## Compliance Standards
- Records all scan results to `AI_Employee_Vault/Logs/`.
- All vulnerability findings are flagged for High-Priority Human-In-The-Loop (HITL) review.
